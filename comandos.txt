===========================================================================
  INSTRUCCIONES DE INSTALACIÓN (paso a paso)
===========================================================================

--- 1. CLONAR / DESCARGAR EL PROYECTO ---

  git clone <url-del-repositorio>
  cd Automatizacion_formularios


--- 2. CONFIGURAR EL BACKEND (Python) ---

  # Ir a la carpeta backend
  cd backend

  # Crear entorno virtual
  python -m venv venv

  # Activar el entorno virtual (Windows)
  .\venv\Scripts\activate

  # Instalar todas las dependencias
  pip install -r requirements.txt

  # Volver a la raíz del proyecto
  cd ..


--- 3. CONFIGURAR EL FRONTEND (Node.js) ---

  # Instalar dependencias de Node.js
  npm install


--- 4. INICIAR EL PROYECTO ---

  # Terminal 1 - Backend (desde la carpeta /backend con venv activado):
  .\venv\Scripts\uvicorn app.main:app --reload --port 8000

  # Terminal 2 - Frontend (desde la raíz del proyecto):
  npm run dev

  # El frontend estará disponible en:  http://localhost:5173
  # El backend (API) estará en:        http://localhost:8000
  # Documentación de la API:           http://localhost:8000/docs


--- 5. CREDENCIALES POR DEFECTO ---

  Usuario administrador creado automáticamente al iniciar el backend:
  DNI:        10000000
  Contraseña: admin123


===========================================================================
  NOTAS IMPORTANTES
===========================================================================

  - La base de datos SQLite (legajos.db) se crea automáticamente al
    iniciar el backend por primera vez. No requiere configuración extra.

  - Los archivos de legajos se guardan en: backend/legajos/

  - Si Tesseract NO está instalado, el sistema igual funciona usando
    EasyOCR como motor OCR principal (recomendado).

  - La primera vez que se suba una foto o un DNI, EasyOCR descargará
    sus modelos automáticamente (~200MB). Requiere conexión a internet.

  - MediaPipe también descarga sus modelos automáticamente la primera
    vez que se procese una foto personal (~50MB).
